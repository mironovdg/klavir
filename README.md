# Клавир

Онлайн-тренажёр: нотная грамота, сольфеджио, пение нот, фортепиано.

- Основной адрес — https://mironovdg.github.io/klavir/ (GitHub Pages, репозиторий github.com/mironovdg/klavir). Там работают микрофон, MIDI и скачивание PDF; прогресс хранится в браузере и переносится между устройствами файлом («Настройки»).
- Копия на claude.ai: https://claude.ai/artifact/ThwUrhkyQoA9oZkQV73LQf (приватная ссылка). Прогресс хранится в учётной записи; микрофон и MIDI браузер там не даёт.
- Версия для других людей будет в Yandex Cloud: сервер, вход по почте, общий прогресс.

## Файлы

- `index.html` — весь сайт: разделы, звук, нотный стан, тренажёры, определение высоты голоса (YIN), подсказки (словарь `HINTS`).
- `docs/manifest.json` — список документов: название, описание, версия, дата обновления.
- `docs/*.html` — документы плана проекта (раздел «Документы» на сайте).

## Правила

- Утверждённое изменение сразу вносится в документы: версия и дата в `manifest.json` и в шапке документа, запись в «Журнал изменений». Новая дата снова делает документ «не прочитан».
- Изменение функций сразу отражается в подсказках (`HINTS`), в `docs/guide.html` и здесь.

## Публикация

- GitHub Pages: закоммитить и отправить в ветку `main`; Pages раздаёт корень репозитория.
- claude.ai: перепубликовать `index.html` вместе с папкой `docs` в тот же артефакт (capabilities: db, user, downloads).
- Локальный просмотр: `python -m http.server 8765` в этой папке, затем http://localhost:8765/.
