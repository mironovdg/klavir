# Клавир

Онлайн-тренажёр: нотная грамота, сольфеджио, фортепиано. Сайт: https://claude.ai/artifact/ThwUrhkyQoA9oZkQV73LQf (приватная ссылка).

## Файлы

- `index.html` — весь сайт: разделы, звук, нотный стан, тренажёры, подсказки (словарь `HINTS`).
- `docs/manifest.json` — список документов: название, описание, версия, дата обновления.
- `docs/*.html` — документы плана проекта (раздел «Документы» на сайте).

## Правила

- Утверждённое изменение сразу вносится в документы: версия и дата в `manifest.json` и в шапке документа, запись в «Журнал изменений». Новая дата снова делает документ «не прочитан».
- Изменение функций сразу отражается в подсказках (`HINTS`), в `docs/guide.html` и здесь.

## Публикация

Перепубликовать `index.html` вместе с папкой `docs` в тот же артефакт (capabilities: db, user, downloads).
Локальный просмотр: `python -m http.server 8765` в этой папке, затем http://localhost:8765/.
