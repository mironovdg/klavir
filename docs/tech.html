Как устроен прототип

  • Одна веб-страница, работает в браузере на компьютере и телефоне. Ничего устанавливать не нужно.
  • Две копии одной страницы: на GitHub Pages — основной адрес mironovdg.github.io/klavir, и на claude.ai (приватная ссылка).
  • Код лежит в публичном репозитории github.com/mironovdg/klavir. Изменения попадают на сайт через 1–2 минуты после отправки в ветку main.
  • Звук пианино синтезируется в браузере (Web Audio), без загрузки записей.
  • Ноты рисуются прямо на странице; значки ключей — шрифт Noto Music.
  • Прогресс: на claude.ai — в хранилище вашей учётной записи и в браузере; на GitHub Pages — только в браузере, пока нет сервера в Yandex Cloud. Между устройствами прогресс переносится файлом JSON («Настройки» → «Перенос на другое устройство»).
  • Высота голоса определяется алгоритмом YIN прямо в браузере; звук никуда не отправляется.
  • Кнопка «PDF» собирает файл в браузере. На claude.ai сайт спрашивает разрешение на сохранение, на GitHub Pages файл скачивается сразу.
  • Исходники лежат в папке C:\claude\pianino.

Ограничения копии на claude.ai

  • В рамке claude.ai браузер не даёт доступа к MIDI и микрофону. Для пения и игры на инструменте открывайте версию на GitHub Pages.
  • Печать страницы из рамки не работает, поэтому вместо неё кнопка «PDF».
  • Web MIDI работает в Chrome, Edge и на Android. В Safari на iPhone и iPad его нет.

Где живёт сайт

решено Для себя — GitHub Pages. Для других — Yandex Cloud: аккаунт уже есть, там будут сервер, вход по почте и общий прогресс. Подключаем на этапе «Для других» или раньше, если понадобится общий прогресс на двух устройствах. Сравнение вариантов:

ВариантПлюсыМинусы
GitHub Pages или NetlifyБесплатно, настраивается за 10 минутСерверы за рубежом; для чужих пользователей с аккаунтами не подойдёт
Yandex Cloud (Object Storage + база)Серверы в России, подходит для версии «для других»Нужен аккаунт и оплата (небольшая)
Хостинг, где уже работает другой ваш сайтВсё в одном местеЗависит от того, где он размещён

Репозиторий публичный: код и документы плана видны всем, личных данных в них нет. Прогресс пользователя в репозиторий не попадает.

Что добавится дальше

  • VexFlow или OpenSheetMusicDisplay — полноценные ноты с тактами и длительностями, чтение MusicXML.
  • Tone.js с записями настоящего рояля — более естественный звук.

Данные пользователей

Пока сайтом пользуетесь только вы, никаких обязательств нет. Для других людей нужно выполнить 152-ФЗ: хранить персональные данные в России, собирать минимум (почта и прогресс), опубликовать политику обработки. Ноты — только из общественного достояния или по лицензии.
