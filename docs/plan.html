План проекта: направления и статусы

Версия 1.5 · обновлён 27.09.2026, 00:30

Цель

Адрес сайта: mironovdg.github.io/klavir. Копия на claude.ai хранит прогресс в учётной записи, но без микрофона и MIDI.

Онлайн-сервис, чтобы научиться нотной грамоте, сольфеджио и игре на фортепиано без преподавателя. Постановку рук, посадку и аппликатуру ставит живой преподаватель. Сначала сервис делается для себя, потом открывается для других.

Утверждённые решения

  • Сервис работает в браузере, без установки программ.
  • Постановка рук — с преподавателем; сервис её не заменяет.
  • Инструмента пока нет. Прототип работает с экранной клавиатурой и клавиатурой компьютера.
  • План ведётся в нескольких документах в разделе «Документы». Каждое утверждённое изменение сразу вносится в них: версия, дата, журнал изменений.
  • Подсказки на сайте («?» в каждом разделе) и «Инструкция пользователя» меняются вместе с функциями.
  • Сайт для себя размещается на GitHub Pages. Версия для других людей — в Yandex Cloud (аккаунт уже есть): сервер, вход по почте, прогресс на всех устройствах.
  • Yandex Cloud подключаем на этапе «Для других» или раньше, если понадобится регулярно заниматься с двух устройств. До этого прогресс переносится файлом.
  • Пение нужно: раздел «Пение» с микрофоном входит в программу.
  • Обучение с нуля: объяснения простыми словами, новые понятия по одному, сразу задание; ноты учим от ориентиров, по уровням, с целью по скорости.
  • Названия нот по-русски: до, ре, ми… с фиксированным «до», как в музыкальной школе. Латинские C, D, E можно включить в настройках.

Нужно ваше решение

  1. Бюджет на инструмент. Варианты — в документе «Инструмент». От бюджета зависит, когда начнём раздел игры.
